## Should add

- **Supabase Auth stores the IP address and user agent with each session** in its own tables. We
  can't turn this off. They're deleted with the session (and with the account).
- **The new-device check:** if we see many wrong passwords on your account from different places,
  the next sign-in from a new device asks for a code we email you. Nothing else changes and nobody is
  told.
- **Sign-in pauses** never lock the account; they pause that device or network for that email.
- **No tracking in emails** (no pixels, no tracked links), and **no third-party analytics on sign-in
  screens**.
- Location: the draft says "We do not collect your precise location". Still true — we don't look up
  a town from the IP yet (SPEC-QUESTIONS Q-GEOIP). If that's added later, say "an approximate town
  from your IP address, shown in your list of signed-in devices".
